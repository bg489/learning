# Flutter Recall

Web học kiểu Memorize được tạo từ tài liệu Flutter đã cung cấp.

## Chạy

- Cách nhanh nhất: mở `index.html` bằng Chrome/Edge.
- Hoặc dùng VS Code + Live Server.

## Tính năng

- 98 câu hỏi đầy đủ từ tài liệu.
- Flashcard lật 3D và spaced repetition.
- Quiz 10 câu có timer, combo, XP và hiệu ứng âm thanh.
- Ôn lại câu sai và kho câu hỏi có tìm kiếm/lọc.
- Lưu tiến độ bằng LocalStorage, không cần backend.
- Responsive cho desktop và điện thoại.
- Âm thanh được tạo bằng Web Audio API, không cần file MP3.

## Phím tắt

- Flashcard: `Space` lật thẻ, `1–4` đánh giá mức nhớ.
- Quiz: `1–4` chọn đáp án, `Enter` sang câu tiếp theo.
